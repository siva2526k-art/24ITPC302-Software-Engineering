Question 1 2 Marks | K2 | Unit 4
Define McCabe's Cyclomatic Complexity V(G) and state its three calculation formulas.
Model Answer:

Cyclomatic Complexity \(V(G)\) defines the upper bound on the number of linearly independent paths through program source code.
1. Edges and Nodes: \(\mathbf{V(G) = E - N + 2P}\) (where \(P=1\)).
2. Predicate Nodes: \(\mathbf{V(G) = P' + 1}\) (where \(P'\) = decision nodes).
3. Enclosed Regions: \(\mathbf{V(G) = \text{Enclosed Regions} + 1}\) (outer region).

Question 2 2 Marks | K2 | Unit 4
Differentiate between Test Drivers and Test Stubs in Integration Testing.
Model Answer:

• Test Driver: A dummy main program that invokes the module under test and passes test data. Used in Bottom-Up Integration Testing.
• Test Stub: A dummy called module that simulates the behavior of a subordinate submodule. Used in Top-Down Integration Testing.

Question 4 2 Marks | K2 | Unit 5
In Earned Value Analysis (EVA), define Cost Variance (CV) and Schedule Variance (SV). How are negative values interpreted?
Model Answer:

• Cost Variance: \(CV = EV - AC\). \(CV < 0 \implies\) Over Budget (Cost Overrun).
• Schedule Variance: \(SV = EV - PV\). \(SV < 0 \implies\) Behind Schedule (Delayed).

Question 5 2 Marks | K2 | Unit 6
Define Risk Exposure (RE) and state the formula for Risk Reduction Leverage (RRL).
Model Answer:

• Risk Exposure: \(\mathbf{RE = P \times C}\) (Probability \(\times\) Impact Cost).
• Risk Reduction Leverage: \(\mathbf{RRL = \frac{RE_{\text{before}} - RE_{\text{after}}}{\text{Cost of Action}}}\). Action is justified if \(RRL > 1.0\).

Question 7 (a) 13 Marks | K3 | Unit 5
A software project is estimated to be 35 KLOC. Compute Effort, Duration, Staff Size, and Productivity if developed in:
(i) Organic Mode, and (ii) Embedded Mode under Barry Boehm's Basic COCOMO I model. [13M]
Detailed Model Answer:
Step 1: Governing Formulas

\[ \mathbf{E = a \cdot (KLOC)^b \text{ [PM]}}, \qquad \mathbf{D = c \cdot (E)^d \text{ [Months]}}, \qquad \mathbf{P = \frac{E}{D} \text{ [Staff]}} \]

Step 2: Organic Mode Calculations (\(a=2.4, b=1.05, c=2.5, d=0.38\))

• Effort: \(E = 2.4 \times (35)^{1.05} = 2.4 \times 41.761 = \mathbf{100.23 \text{ Person-Months}}\)
• Duration: \(D = 2.5 \times (100.23)^{0.38} = 2.5 \times 5.764 = \mathbf{14.41 \text{ Months}}\)
• Staff Size: \(P = 100.23 / 14.41 = \mathbf{6.96 \approx 7 \text{ Persons}}\)
• Productivity: \(35,000 / 100.23 = \mathbf{349.2 \text{ LOC/PM}}\)

Step 3: Embedded Mode Calculations (\(a=3.6, b=1.20, c=2.5, d=0.32\))

• Effort: \(E = 3.6 \times (35)^{1.20} = 3.6 \times 71.026 = \mathbf{255.69 \text{ Person-Months}}\)
• Duration: \(D = 2.5 \times (255.69)^{0.32} = 2.5 \times 5.922 = \mathbf{14.81 \text{ Months}}\)
• Staff Size: \(P = 255.69 / 14.81 = \mathbf{17.26 \approx 18 \text{ Persons}}\)
• Productivity: \(35,000 / 255.69 = \mathbf{136.9 \text{ LOC/PM}}\)

✓ Final Answer: Organic: 100.2 PM (7 Persons, 14.4 Mos) | Embedded: 255.7 PM (18 Persons, 14.8 Mos)

Question 7 (b) 13 Marks | K3 | Unit 5
(i) Explain Albrecht's Function Point (FP) Model. Detail the 5 information domain characteristics and the 14 complexity adjustment factors. [7M]
(ii) A system has UFC = 369. All 14 complexity factors are rated 3. Compute VAF, FP, and estimated Java size (53 LOC/FP). [6M]
Detailed Model Answer:
Part (i): FP Theory & Formula [7 Marks]

\[ \mathbf{FP = UFC \times VAF = UFC \times \left(0.65 + 0.01 \sum_{i=1}^{14} F_i\right)} \]

• 5 Domain Characteristics: External Inputs (EI), External Outputs (EO), External Inquiries (EQ), Internal Logical Files (ILF), External Interface Files (EIF).
• 14 Factors: Data communications, distributed processing, performance, transaction rate, online data entry, end-user efficiency, online update, complex processing, reusability, installation ease, operational ease, multiple sites, facilitate change.

Part (ii): Worked Numerical Solution [6 Marks]

• \(\sum F_i = 14 \times 3 = 42 \implies VAF = 0.65 + 0.01(42) = \mathbf{1.07}\)
• \(FP = 369 \times 1.07 = \mathbf{394.83 \text{ Function Points}}\)
• Java Size: \(394.83 \times 53 = \mathbf{20,926 \text{ LOC} \ (20.93 \text{ KLOC})}\).

✓ Final Answer: VAF = 1.07 | FP = 394.83 | Java Code Size = 20.93 KLOC
Question 8 (a) 14 Marks | K3 | Unit 5
A project has BAC = $150,000, 10 months duration. At Month 5, records reveal:
PV = $75,000, EV = $60,000, AC = $70,000.
Calculate CV, SV, CPI, SPI, EAC, and ETC. Audit project health and recommend management action. [14M]
Detailed Model Answer:
Step 1: Variances & Performance Indices

• Cost Variance: \(CV = EV - AC = 60,000 - 70,000 = \mathbf{-\$10,000}\) (\(CV < 0 \implies\) Over Budget by $10,000).
• Schedule Variance: \(SV = EV - PV = 60,000 - 75,000 = \mathbf{-\$15,000}\) (\(SV < 0 \implies\) Behind Schedule by $15,000).
• Cost Performance Index: \(CPI = \frac{EV}{AC} = \frac{60,000}{70,000} = \mathbf{0.857}\) (Only $0.86 value earned per $1 spent).
• Schedule Performance Index: \(SPI = \frac{EV}{PV} = \frac{60,000}{75,000} = \mathbf{0.800}\) (Progressing at only 80% planned velocity).

Step 2: Forecasting Total Cost & Completion

• Estimate at Completion: \(EAC = \frac{BAC}{CPI} = \frac{150,000}{0.8571} = \mathbf{\$175,000}\) (Projected cost overrun: $25,000).
• Estimate to Complete: \(ETC = EAC - AC = 175,000 - 70,000 = \mathbf{\$105,000}\).

Step 3: Management Health Audit & Action

Project is in Critical Condition (both cost overrun and schedule slippage). Management must: (1) Freeze scope additions; (2) Reassign senior staff to critical path activities; (3) Negotiate revised timeline with client.

✓ Final Answer: CV = -$10k | SV = -$15k | CPI = 0.857 | SPI = 0.800 | EAC = $175,000 | ETC = $105,000
