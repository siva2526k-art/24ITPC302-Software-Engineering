## 🎯 Pedagogical Principles & Standards

1. **Rigorous Academic & Industry Alignment:**

2. **Full Step-by-Step Numerical Precision:**
   - Software Engineering includes crucial quantitative/numerical exam models:
     - **Function Point (FP) Calculation:** Unadjusted Function Counts ($UFC$), Value Adjustment Factor ($VAF = 0.65 + 0.01 \sum F_i$), and $FP = UFC \times VAF$.
     - **COCOMO I (Basic & Intermediate):** Effort $E = a(KLOC)^b$, Development Time $D = c(E)^d$, People $P = E/D$ across Organic, Semidetached, and Embedded modes.
     - **COCOMO II:** Early Design & Post-Architecture estimation models.
     - **Cyclomatic Complexity ($V(G)$):** Flow graph analysis:
       1. $V(G) = E - N + 2P$
       2. $V(G) = P + 1$ (Predicate nodes $+ 1$)
       3. $V(G) = \text{Number of enclosed regions } R$
     - **Earned Value Analysis (EVA):** Planned Value ($PV$), Earned Value ($EV$), Actual Cost ($AC$), Cost Variance ($CV = EV - AC$), Schedule Variance ($SV = EV - PV$), Cost Performance Index ($CPI = EV/AC$), Schedule Performance Index ($SPI = EV/PV$).
     - **Risk Exposure ($RE$):** $RE = P \times C$ (Probability $\times$ Impact Cost).
   - **Rule:** Never jump steps in numerical problems. Show data identification, formula citation, substitution, arithmetic, unit specification, and engineering interpretation.
