## 🏛️ Examination Structure & Mark Distribution

Under Autonomous Regulations 2024, the End-Semester Examination (100 Marks) follows the standard question pattern:

| Part | Question Format | Options / Choice | Mark Breakdown | Total Marks | Target Bloom's Levels |
| :---: | :--- | :--- | :---: | :---: | :---: |
| **Part A** | 10 Short Conceptual Questions (Q1 to Q10) | Compulsory (No Choice, ~1–2 questions per module) | $10 \times 2\text{ Marks}$ | **20 Marks** | K1 (Remember), K2 (Understand) |
| **Part B** | 5 Long Descriptive / Numerical Questions (Q11 to Q15) | Either/Or Choice per question (Covering Modules I to V/VI) | $5 \times 13\text{ Marks}$ | **65 Marks** | K2 (Understand), K3 (Apply), K4 (Analyze) |
| **Part C** | 1 Advanced Application / Comprehensive Case Study (Q16) | Either/Or Choice (Cross-module system engineering) | $1 \times 15\text{ Marks}$ | **15 Marks** | K3 (Apply), K4 (Analyze), K5 (Evaluate) |
| **Total** | - | - | - | **100 Marks** | **Duration: 3 Hours** |

## 🎯 The Examiner's Standard 13-Mark Combo Patterns

University examiners consistently test specific topic pairings:

1. **Module I Combos:**
   - *Combo 1.1 (13M):* Linear Sequential (Waterfall) vs Boehm's Spiral Model — Detailed comparison of phases, risk management, and applicability.
   - *Combo 1.2 (13M):* Agile Process Framework & Extreme Programming (XP) — Core values, user stories, refactoring, pair programming, and continuous integration.
2. **Module II Combos:**
   - *Combo 2.1 (13M):* Software Requirements Specification (SRS) IEEE 830 Structure + Requirements Engineering Process (Elicitation to Validation).
   - *Combo 2.2 (13M):* Classical Analysis Modeling: Data Flow Diagram (DFD) Level 0 & Level 1 + Petri Net model for a concurrent system (e.g., Producer-Consumer or ATM).
3. **Module III Combos:**
   - *Combo 3.1 (13M):* Design Concepts: Modularity, Information Hiding + In-depth Hierarchy of Cohesion (7 levels) and Coupling (6 levels).
   - *Combo 3.2 (13M):* Architectural Design: Layered Architecture vs Pipe-and-Filter Architecture + Transform Mapping from DFD to Structure Chart.
4. **Module IV Combos:**
   - *Combo 4.1 (13M):* White-Box Basis Path Testing: Flow Graph construction, Cyclomatic Complexity calculation ($V(G)$ using all 3 methods), and Deriving Independent Paths.
   - *Combo 4.2 (13M):* Black-Box Testing: Equivalence Partitioning & Boundary Value Analysis for input specifications + Integration Testing strategies (Top-Down with Stubs vs Bottom-Up with Drivers).
5. **Module V Combos:**
   - *Combo 5.1 (13M):* Sizing & Estimation: Complete Function Point (FP) calculation problem ($UFC \times VAF$) + Basic COCOMO I Effort and Schedule computation across Organic, Semidetached, and Embedded modes.
   - *Combo 5.2 (13M):* Project Scheduling & Earned Value Analysis: PERT/CPM Critical Path determination + EVA metrics ($PV, EV, AC, CV, SV, CPI, SPI$).
6. **Module VI Combos:**
   - *Combo 6.1 (13M):* Software Risk Management: Risk Table construction, Risk Exposure ($RE = P \times C$) + Detailed RMMM Plan (Mitigation, Monitoring, Management).
   - *Combo 6.2 (13M):* CASE Tools: Integrated CASE Environment Architecture (Central Repository / OMS, Integration Services) + Classification (Upper, Lower, and Integrated CASE).
