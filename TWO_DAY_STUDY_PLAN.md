# 24ITPC302: 48-Hour Fast-Track Study & Revision Plan
### Course: 24ITPC302 – Software Engineering (Regulations 2024)

This revision guide schedules 48 hours of focused exam preparation into four distinct 12-hour high-yield blocks.

---

## 🗓️ DAY 1: SDLC MODELS, REQUIREMENTS & ARCHITECTURE

### Block 1 (Morning: Hours 01 to 06) — Module I & II Foundations
- **01:00 - 03:00:** Module I Prescriptive Models: Waterfall vs Spiral (4 quadrants), V-Model V&V mapping, RAD, Prototyping.
- **03:00 - 04:30:** Agile Frameworks: 4 Agile Manifesto values, 12 Principles, Extreme Programming (XP lifecycle, Pair programming, TDD).
- **04:30 - 06:00:** Module II Requirements: Functional vs Non-Functional (FURPS+), IEEE 830 standard SRS outline, Feasibility types.

### Block 2 (Afternoon/Evening: Hours 07 to 12) — Module II & III Modeling & Design
- **07:00 - 09:00:** Classical Analysis Modeling: DFD Level 0 and Level 1 balancing rules, Petri Nets (Places, Transitions, Tokens, Marking, Firing).
- **09:00 - 10:30:** Module III Design Principles: Information Hiding, Cohesion (7 levels with code examples), Coupling (6 levels).
- **10:30 - 12:00:** Architectural Styles (Layered, Pipe-and-Filter, Repository), Transform Mapping procedure from DFD to Structure Chart, UI Golden Rules.

---

## 🗓️ DAY 2: TESTING, PROJECT SIZING, ESTIMATION & RISK

### Block 3 (Morning: Hours 13 to 18) — Module IV Testing & Reengineering
- **13:00 - 15:30:** White-Box Basis Path Testing: Control Flow Graph (CFG), Cyclomatic Complexity $V(G) = E - N + 2 = P + 1 = R$, Independent basis path derivation, Test suite design.
- **15:30 - 17:00:** Black-Box Testing: Equivalence Class Partitioning, Boundary Value Analysis (BVA), Testing Levels (Unit, Integration with stubs/drivers, Alpha, Beta, System).
- **17:00 - 18:00:** Software Maintenance (Corrective, Adaptive, Perfective, Preventive), BPR, Software Reengineering Process Model (Reverse vs Forward).

### Block 4 (Afternoon/Night: Hours 19 to 24) — Module V & VI Quantitative Management
- **19:00 - 21:00:** Software Sizing & Estimation: Function Point ($FP = UFC \times VAF$) complete numerical working, Basic & Intermediate COCOMO I equations across Organic, Semidetached, and Embedded modes.
- **21:00 - 22:30:** Project Scheduling: CPM Network Diagram, Critical Path ($Slack = 0$), Earned Value Analysis ($CV, SV, CPI, SPI, EAC$).
- **22:30 - 24:00:** Module VI Risk & CASE: Risk Exposure ($RE = P \times C$), RMMM Plan (Mitigation, Monitoring, Management), CASE Environment Architecture (OMS & Tool Integration), Upper/Lower/I-CASE tools.
